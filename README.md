# Local-occurrence-and-climate-suitability-of-Coffea-fadenii-and-Afrocarpus-usambarensis

[Project website](https://geraldkaniaru.github.io/local-occurrence-and-climate-suitability-of-Coffea-fadenii-and-Afrocarpus-usambarensis/)
We compared the woody assemblages in Ngangao and Mbololo forest fragments, documented the local occurrence and size structure of Coffea fadenii and Afrocarpus usambarensis, and identified areas across Kenya with potentially suitable climates for restoration or where previously undocumented populations may occur.
